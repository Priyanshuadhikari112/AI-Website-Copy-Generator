# AI Website Copy Generator for Local Businesses

## Overview

This project was developed as part of **Future Interns – Prompt Engineering Task 1 (2026)**.

The objective of this project is to design a structured prompt system that generates professional, conversion-focused website copy for local businesses. Instead of using a single prompt, the project follows a modular approach by separating different website components into specialized prompts.

---

## Business Chosen

**Business Name:** The Black Coffee Cafe

**Location:** Greater Noida

**Business Type:** Modern Café

---

## Project Objective

The prompt framework is designed to generate:

- Homepage copy
- Services page content
- Call-To-Action (CTA) sections
- Tone-adaptable website content
- Complete website copy for publishing

---

## Prompt Files

| File | Purpose |
|------|---------|
| 01_Business_Analysis.md | Analyze the business and target audience |
| 02_Homepage_Copy.md | Generate homepage content |
| 03_Service_Page.md | Create services page content |
| 04_CTA_Generator.md | Generate persuasive CTA sections |
| 05_Tone_Adapter.md | Adapt website copy for different brand tones |
| 06_Master_Prompt.md | Generate the complete website copy |

---

## Output Files

- homepage.md
- services.md
- cta.md
- complete_website_copy.md
